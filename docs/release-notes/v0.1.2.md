Torno 0.1.2 arregla el aviso de actualizaciones: buscar una versión nueva ya no falla con un error 403 y las descargas que se cortan se reanudan.

*Torno 0.1.2 fixes update notifications: checking for a new version no longer fails with a 403 error, and downloads that drop are resumed.*

> [!IMPORTANT]
> Torno está en una fase temprana: guarda a menudo y avísanos de lo que falle.
> Torno is at an early stage: save often and tell us what goes wrong.

## Español

### Correcciones

- **Buscar actualizaciones:** cuando GitHub rechaza la consulta por su límite de peticiones (el error 403, que comparten todos los programas de la misma red), Torno pregunta a la página de versiones y sigue avisando de la versión nueva.
- **Descargas que se cortan:** si la conexión se cae o se queda parada, la descarga del paquete continúa donde iba en lugar de empezar de cero o fallar por tiempo agotado.

## English

### Fixes

- **Checking for updates:** when GitHub refuses the check for its request limit (the 403 error, which every program on the same network shares), Torno asks the release page and still announces the new version.
- **Interrupted downloads:** when the connection drops or stalls, the package download continues where it left off instead of starting over or failing with a timeout.
